# Bazar Dor 🛒
https://a7-bazar-dor-eight.vercel.app/

## 📌 Project Description

**Bazar Dor** is a simple platform for tracking the daily prices of essential commodities and understanding price changes. Users can view product prices, compare prices across different markets, and identify price increases or decreases.

## 🛠️ Technologies Used

* **Tailwind CSS** — Utility-first styling
* **DaisyUI** — UI components
* **TypeScript** — Type-safe development
* **Next.js** — React-based web framework
* **Better Auth** — Authentication and user management
* **MongoDB** — Database for storing application data

## ✨ Key Features

1. **Daily Product Prices** — View the current prices of essential commodities.
2. **Price Change Tracking** — Identify whether product prices have increased or decreased.
3. **Category-Based Search** — Find products by category.
4. **Price Sorting** — Sort products from lowest to highest price or vice versa.
5. **Market Price Comparison** — Compare the minimum, maximum, and average prices of products across different markets.

## 🎯 Project Goal

To make daily market prices easier to access and help users make informed purchasing decisions through price tracking and market comparisons.
